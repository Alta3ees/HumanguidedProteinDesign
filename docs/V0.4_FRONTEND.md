# v0.4 Frontend Foundation

The first v0.4 slice is a read-only research workspace over the canonical Python/JSON archive.

## Architecture

```text
data/projects/*/design_archive.json
        |
        v
human_protein_design.archive
        |
        v
FastAPI read-only API
        |
        v
React + TypeScript + Vite workspace
```

The browser does not read or mutate archive files directly. The Python archive remains the source of truth.

## Current UI

- project picker
- project objective summary
- project counts
- clickable design lineage tree
- design status/origin/decision
- sequence display
- structural hypotheses with provenance/confidence metrics
- evidence counts and evidence records
- human decision rationale

## Run locally

From the repository root, install the Python web dependencies:

```bash
pip install -e ".[web]"
```

Start the API:

```bash
uvicorn human_protein_design.web.api:app --reload
```

In a second terminal:

```bash
cd frontend
npm install
npm run dev
```

Open the local Vite URL printed by the command, normally `http://localhost:5173`.

The Vite development server proxies `/api` to the Python API on port 8000.

## Projects root

By default the API discovers projects under:

```text
data/projects/
```

To use another location:

```bash
HGD_PROJECTS_ROOT=/path/to/projects uvicorn human_protein_design.web.api:app --reload
```

## Validation

Run Python tests with:

```bash
pytest -q
```

Check the frontend build with:

```bash
cd frontend
npm install
npm run build
```

## Deliberate v0.4 limitation

This first slice is read-only. Do not add archive writes directly in React. Future mutation, decision, evidence, and structure actions should be implemented as validated Python API endpoints that call the existing archive/domain model.
