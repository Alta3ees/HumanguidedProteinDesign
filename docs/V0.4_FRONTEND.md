# v0.4 Frontend Foundation

v0.4 is a local research workspace over the canonical Python/JSON archive.
The archive remains the source of truth; the browser never edits JSON files directly.

## Architecture

```text
data/projects/*/design_archive.json
        |
        v
human_protein_design.archive
        |
        v
local FastAPI server (127.0.0.1)
        |
        v
React + TypeScript + Vite workspace (localhost)
```

No project data is sent to a hosted service. During development, both servers run only on the scientist's machine. A later release can serve the compiled React bundle directly from Python so normal users do not need the Vite development server.

## Current UI

- project picker
- scientific objective and project counts
- node-link design mindmap with parent/child edges
- accepted/rejected/deferred/status visualization
- clickable design inspection
- sequence display
- structural hypotheses with provenance/confidence metrics
- PyRosetta parent score, design score, delta score, and stored Rosetta score terms
- evidence counts and complete evidence records
- human decision rationale
- local file import/attachment for computational, experimental, literature, and note evidence

## Local evidence import

Select a design in the mindmap and use **Import evidence** in the inspector.
The browser file picker can attach one or more local files such as:

- NMR spectra/raw files
- SEC/MALS/CD/SPR exports
- CSV/TSV tables
- images and plots
- PDFs
- PyMOL or computational outputs
- arbitrary raw instrument/model files

The server copies the files into that project's local `evidence/` directory and records project-relative paths in `design_archive.json`. Files are preserved as supplied; v0.4 does not yet parse specialized scientific formats.

## Run locally

From the repository root:

```bash
python -m pip install -e ".[web]"
```

Start the local API:

```bash
uvicorn human_protein_design.web.api:app --reload
```

In a second terminal:

```bash
cd frontend
npm install
npm run dev
```

Open the local Vite URL, normally `http://localhost:5173`.
The Vite server proxies `/api` to the Python process on port 8000.

## Projects root

Default:

```text
data/projects/
```

Override it locally with:

```bash
HGD_PROJECTS_ROOT=/path/to/projects uvicorn human_protein_design.web.api:app --reload
```

## Validation

```bash
pytest -q
```

and:

```bash
cd frontend
npm install
npm run build
```

## Scope boundary

v0.4 currently exposes project data and permits **evidence import only**. Mutation proposals, Rosetta execution, accept/reject decisions, sequence design, and structure generation remain outside the frontend for now.

When those actions are added later, they must go through validated Python API/domain methods rather than direct browser-side archive manipulation.
